# THE SIMPLICITY PACT
Before presenting any code, ask yourself:

✅ Is this the simplest possible solution to the specific problem stated?
✅ Did I avoid adding configuration flags that weren't requested?
✅ Did I ignore "impossible" edge cases (as per CLAUDE.md)?
✅ Did I leave the surrounding code exactly as I found it?
✅ Are there any abstractions created for single-use code? (If yes, inline it.)
